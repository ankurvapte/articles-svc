Request workflow: listing technology articles

What happens inside the container for GET /api/v1/articles?category=technology, from the moment the request arrives until the JSON goes back.

422 validation_error

The Router rejects a bad query, for example ?category=gossip, before any use case runs.

404 not_found

ArticleService raises ArticleNotFound, and a handler in main.py turns it into the standard error shape.

503 not_ready

/health/ready returns this when news.json failed to load, so no traffic is routed to the container.
